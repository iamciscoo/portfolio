# Authentic personal photography

Four authentic photographs were selected on 22 October 2026. Both Instagram profiles were visually inspected through the already authenticated Chrome session, including the normally accessible private profile. No credentials or cookies were extracted and no access controls were bypassed.

See manifest.json for sources, dimensions, approval and placements. Both original uploads are used. Instagram supplies a candid portrait and a TIMUN event photo. The GloboExpats workstation video cover was viewed but its media download did not complete; it is not included.

WebP encoding strips metadata and leaves faces unchanged. Originals remain untouched. Next Image serves responsive variants; the hero is prioritized. No photo is labeled as taken in Russia without location evidence. A sharper professional portrait or explicitly identified Russia photo can be added later; neither is required for this design.
